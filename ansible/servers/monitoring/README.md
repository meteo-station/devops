# Последовательность настройки сервера мониторинга

1. Установка пользователей на сервер
```sh
make init-users
```

2. Общая настройка сервера для мониторинга
```sh
make setup-server
```
- Настройка необходимого файлового окружения проекта
- Установка докера
- Настройка необходимого окружения в докере и авторизация в Github
- Установка Prometheus
- Установка Grafana
- Установка Nginx
- Настройка Nginx
